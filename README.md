## 💻 Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) (use a current LTS version)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Fazeel2003-md/professional_porfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd professional_porfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables if required by your application. Create a local `.env` file based on `.env.example` and add your own API keys. Never commit real credentials.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal, commonly `http://localhost:5173`.
